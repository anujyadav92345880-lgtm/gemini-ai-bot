# Data Storage Recharge Website

## Project Description
A complete web application where users can:
1. Recharge mobile data/MB
2. Store extra MB for future use
3. Use stored MB when current recharge is exhausted

## Tech Stack
- **Frontend:** React.js, Axios, React Router
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT (JSON Web Tokens)
- **Payment:** Razorpay Integration

## Project Structure
